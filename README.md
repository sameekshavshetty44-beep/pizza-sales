# 🍕 Pizza Sales Analysis Project

## 📌 Project Overview
This project focuses on analyzing pizza sales data using Python, SQL, Excel, and Power BI. The main objective is to understand sales performance, customer ordering patterns, popular pizza types, and revenue trends through data analysis and visualization.

## 🛠️ Tools & Technologies
- **Python:** Data cleaning, data preprocessing, and exploratory data analysis.
- **SQL:** Querying the data to analyze sales, revenue, and order trends.
- **Microsoft Excel:** Data cleaning, pivot tables, and sales analysis.
- **Power BI:** Interactive dashboards and data visualization.

## 🎯 Project Objectives
- Analyze total sales and revenue.
- Identify the best-selling pizzas.
- Understand daily and monthly order trends.
- Analyze sales performance by pizza category and size.
- Identify key business insights using dashboards.

## 📊 Key Analysis
- Total revenue and total orders.
- Average order value.
- Total pizzas sold.
- Best-selling and least-selling pizzas.
- Daily and monthly sales trends.
- Sales by pizza category and size.

## 💡 Key Insights
The analysis helps identify popular pizza categories, peak ordering periods, and sales trends. These insights can help businesses understand customer preferences and make better business decisions.

## 📂 Project Files
- Python notebook or script
- SQL queries
- Excel analysis file
- Power BI dashboard

## 🚀 Conclusion
This project demonstrates the use of Python, SQL, Excel, and Power BI to clean, analyze, and visualize pizza sales data. It helped me improve my data analytics skills and gain practical experience in turning raw data into meaningful business insights.
